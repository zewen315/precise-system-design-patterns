# Precise System Design Patterns

> Notes and engineering patterns for System Design, Infrastructure, and Production Engineering interviews.

Most interview resources teach **what** to use.

This repository focuses on **why** systems are built the way they are.

Topics are organized around the knowledge expected from modern backend, infrastructure, and SRE engineers, including:

* System Design
* Linux
* Computer Networks
* Distributed Systems
* Databases
* Cloud & Kubernetes
* Observability
* Production Troubleshooting

Rather than memorizing interview answers, the goal is to build a solid mental model that explains how large-scale systems work, fail, and recover.

## Philosophy

Every topic should answer questions like:

* Why is this needed?
* What problem does it solve?
* What trade-offs does it introduce?
* How does it fail?
* How do we debug it?
* What changes at scale?

Understanding these patterns is far more valuable than memorizing individual interview questions.

## Who This Is For

This repository is intended for engineers preparing for roles such as:

* Software Engineer (Backend)
* Production Engineer
* Site Reliability Engineer (SRE)
* Infrastructure Engineer
* Platform Engineer
* Network Software Engineer
